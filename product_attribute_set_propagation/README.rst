This module adds a wizard to propagate attribute set values from one product
to other products that share the same attribute set.

A button "Propagate Attributes" is available on both the product template and
product variant form views when the product has an attribute set assigned.
The wizard allows selecting target products (filtered to the same attribute set)
and copies all attribute values from the source product to the selected targets.
