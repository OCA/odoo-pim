To use this module:

1.  Go to *Inventory \> Products \> Products* (or *Product Variants*).
2.  Click the column-picker icon at the top right of the list and tick
    the attribute columns you want to see.
3.  Tick the checkboxes of several products.
4.  Click on a cell in any of the attribute columns and change the
    value. Odoo will ask whether to update every selected product.
    Confirm and the value is written on all of them.
